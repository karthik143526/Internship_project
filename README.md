# Internship Shopping Website

This repository contains a shopping website built as an internship project.

## Description

- This is a sample shopping website.
- First register, then login.
- The database is connected using XAMPP.
- Technologies used: HTML, CSS, JavaScript, PHP, and MySQL.
- The project includes an admin panel.
- Admin can see orders and manage placed orders.

## How to Run

1. Install XAMPP and start Apache and MySQL.
2. Place this project folder in `C:\xampp\htdocs\flipcart`.
3. Create a MySQL database named `flip`.
4. Import the required tables and data.
5. Open your browser and go to:
   - `http://localhost/flipcart/register.html` to register.
   - `http://localhost/flipcart/login.php` to login.

## Features

- User registration and login.
- Shopping product pages.
- Order placement.
- Admin panel to view orders and manage placed orders.
